月经周期状态插件 v3.0
概述
月经周期状态插件是一个创新的机器人状态模拟插件，它通过双周期锚定模型模拟女性月经周期对机器人状态的影响。该插件让机器人具有生物节律，根据周期阶段自然调整回复风格，增加机器人的真实感和角色沉浸感。

核心特性
双周期锚定模型：创新的周期计算方式，保证每次对话都有自然的周期变化

多维度状态影响：从生理、心理到痛经的多层次状态模拟

智能提示词注入：自动将周期状态信息注入到机器人的提示词中

可配置的影响等级：每个阶段的影响程度均可自定义

随机痛经系统：月经期自动生成痛经等级，增加真实感

双周期锚定模型详解
模型原理
传统的月经周期模拟通常是固定30天循环，但这缺乏真实感。本插件采用双周期锚定模型，其核心原理是：

锚点日期：每月固定的一天（默认为15号）作为周期计算的基准点

双周期设计：每次生成两个连续的月经周期（周期1+周期2）

可变周期长度：每个周期的天数在合理范围内随机变化（25-35天）

真实锚定：周期始终与日历上的锚点日期对齐

周期阶段分配
每个周期包含四个阶段，天数分配规则如下：

阶段	天数分配	描述
月经期	随机3-7天	月经持续期
卵泡期	总天数-月经-16天	恢复期
排卵期	固定2天	最佳状态期
黄体期	固定14天	经前期
周期计算示例
假设：

锚点日期：每月15号

当前日期：2024-01-10

生成周期：周期1=28天，周期2=31天

那么：

起始锚点：2023-12-15

结束锚点：2024-02-15

总天数：59天（28+31）

安装与配置
安装方法
将插件文件夹放置在 plugins 目录下，确保目录结构如下：

text
plugins/
└── mofox_period_plugin/
    ├── __init__.py
    ├── plugin.py
    └── config.toml
配置文件
首次运行会自动生成 config.toml 配置文件：

toml
[plugin]
enabled = true
config_version = "3.0.0"
debug_mode = false

[cycle]
anchor_day = 15  # 锚点日期（1-31）

[levels]
# 各阶段影响等级（1-10，越高影响越大）
menstrual_physical = 5
menstrual_psychological = 4
follicular_physical = 2
follicular_psychological = 2
ovulation_physical = 3
ovulation_psychological = 2
luteal_physical = 4
luteal_psychological = 3
配置说明
插件开关
plugin.enabled: 是否启用插件（true/false）

plugin.debug_mode: 调试模式，输出详细日志

周期设置
cycle.anchor_day: 锚点日期（1-31），建议选择15号左右的日期

影响等级
每个阶段有两个影响等级：

生理影响（physical）：影响精力、体力、疲劳感

心理影响（psychological）：影响情绪、耐心、敏感性

等级范围：1-10

1-3：轻微影响

4-6：中等影响

7-10：严重影响

周期阶段详情
1. 月经期（🩸）
描述：身体不适，情绪敏感，需要更多休息和理解

特点：随机生成痛经等级（0-10），影响回复时的耐心和精力

影响：生理和心理等级较高，回复可能更简短、更情绪化

2. 卵泡期（🌱）
描述：状态恢复，情绪平稳，思维清晰

特点：月经期后的恢复阶段，状态逐渐好转

影响：生理和心理等级较低，回复更加理性、有条理

3. 排卵期（🥚）
描述：状态较佳，情绪积极，表达流畅

特点：周期中的最佳状态期

影响：生理等级适中，心理等级低，回复更加积极、热情

4. 黄体期（🍂）
描述：身体疲惫，情绪波动，需要更多耐心

特点：经前期，状态开始下降

影响：生理和心理等级较高，回复可能更易怒、不耐烦

技术实现
数据结构
python
class DualCycleData:
    """双周期数据"""
    anchor_day: int           # 锚点日期（1-31）
    start_date: datetime      # 起始锚点日期
    cycle1_length: int        # 第一周期天数
    cycle2_length: int        # 第二周期天数
    cycle1_menstrual_days: int # 第一周期月经天数
    cycle2_menstrual_days: int # 第二周期月经天数
    total_days: int           # 总天数
    end_date: datetime        # 结束锚点日期
状态计算流程
检查存储：加载已存储的双周期数据

验证有效期：检查当前日期是否在周期有效期内

重新生成：如果过期或首次运行，生成新的双周期

计算阶段：根据当前日期计算所处阶段和周期内天数

应用配置：读取配置文件中的影响等级

生成提示词：将状态信息格式化为提示词

存储机制
插件使用本地存储API保存：

双周期数据（dual_cycle_data）

锚点日期配置（anchor_day）

数据存储在插件专属的命名空间下，避免与其他插件冲突。

故障排除
常见问题
1. 插件未生效
检查 plugin.enabled 是否为 true

检查日志中是否有插件加载成功的消息

确保配置文件格式正确（TOML格式）

2. 周期状态不更新
使用 /regenerate_cycle 重新生成周期

检查系统时间是否正确

查看日志中是否有错误信息

3. 提示词未注入
检查 debug_mode 查看提示词生成日志

确认目标提示词名称是否正确

检查注入规则的优先级设置

4. 周期天数异常
锚点日期间隔太短可能导致周期异常

建议锚点日期设置在月中（10-20号）

使用 /regenerate_cycle 重新生成
