# MoFox 月经周期插件

让你的 AI 机器人具有真实的生理节律，体验更自然的情感互动。

## 📖 简介

本插件模拟女性月经周期对机器人状态的影响，让机器人在不同周期阶段展现出相应的生理和心理状态，使对话更加真实自然。

## ✨ 核心特性

### 🔄 双周期锚定模型
- 基于每月固定日期（锚点）生成两个真实周期
- 周期长度：25-35天（随机）
- 月经天数：3-7天（随机）
- 自动计算阶段：月经期 → 卵泡期 → 排卵期 → 黄体期

### 📊 等级化影响系统
- **生理影响**：1-10级，数字越大影响越严重
- **心理影响**：1-10级，数字越大波动越明显
- **痛经程度**：0-10级，月经期自动随机生成

### 💬 自然的对话风格
- 根据当前周期状态自动调整回复语气
- 客观中性的状态描述
- 真实的情感表达

## 🎮 使用命令

### 查询当前状态
```
/period
/月经状态
/周期状态
```
显示完整的周期信息：当前阶段、影响等级、双周期数据等。

### 重新生成周期
```
/regenerate_cycle
/重新生成周期
/刷新周期
```
强制重新生成新的双周期数据。

## ⚙️ 配置说明

配置文件位于：`config/plugins/mofox_period_plugin/config.toml`

### 基础设置

```toml
[plugin]
enabled = true          # 是否启用插件
debug_mode = false      # 调试模式

[cycle]
anchor_day = 15         # 锚点日期（1-31），建议15号
```

### 影响等级调整

你可以调整各阶段的影响强度（1-10）：

```toml
[levels]
# 月经期
menstrual_physical = 5        # 生理影响
menstrual_psychological = 4   # 心理影响

# 卵泡期
follicular_physical = 2
follicular_psychological = 2

# 排卵期
ovulation_physical = 3
ovulation_psychological = 2

# 黄体期
luteal_physical = 4
luteal_psychological = 3
```

## 📝 等级说明

### 生理影响
- **1-2级**：状态良好，精力充沛
- **3-4级**：轻度疲劳，略有不适
- **5-6级**：明显疲劳，身体沉重
- **7-8级**：严重不适，活动困难
- **9-10级**：极度不适，需要关注

### 心理影响
- **1-2级**：情绪稳定平和
- **3-4级**：情绪略有波动
- **5-6级**：情绪波动较大，易敏感
- **7-8级**：情绪很不稳定
- **9-10级**：情绪极不稳定

### 痛经等级（月经期自动生成）
- **0级**：无痛经（30%概率）
- **1-3级**：轻度痛经（40%概率）
- **4-6级**：中度痛经（20%概率）
- **7-10级**：重度痛经（10%概率）

## 🔧 工作原理

1. **周期生成**：系统根据锚点日期自动生成两个月的周期数据
2. **状态计算**：每天根据配置的等级和当前阶段计算状态
3. **提示词注入**：将状态信息注入到机器人的回复系统
4. **自然表达**：机器人根据状态自然地调整回复风格

## ⚠️ 注意事项

- 首次安装会自动生成双周期数据
- 配置修改后需要重启机器人或重新生成周期
- 痛经等级不可配置，每天自动随机生成
- 建议锚点日期设在月中（10-20号）
