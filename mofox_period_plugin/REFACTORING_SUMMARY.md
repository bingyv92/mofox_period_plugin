# 月经周期插件重构总结

## 版本信息
- **旧版本**: 1.0 (使用0-1浮点数系统)
- **新版本**: 2.0 (使用1-10整数等级系统)
- **重构日期**: 2025-12-14

## 核心改进

### 1. 命令系统升级
**改动**: 从 `BaseCommand` 迁移到 `PlusCommand`

**理由**: 遵循插件开发指南推荐的最佳实践

**变更内容**:
- ✅ 使用 `PlusCommand` 作为基类
- ✅ 通过 `create_plus_command_adapter` 注册命令
- ✅ 使用 `CommandArgs` 自动解析参数
- ✅ 移除手动正则表达式匹配

**影响的类**:
- [`PeriodStatusCommand`](plugin.py:439)
- [`SetPeriodCommand`](plugin.py:514)

### 2. 等级系统重构
**改动**: 从0-1浮点数改为1-10严格整数等级

**旧系统问题**:
- 范围不直观（0.0-1.0）
- 等级划分不明确
- 难以精确控制影响程度

**新系统优势**:
- ✅ 等级直观（1-10，数字越大影响越严重）
- ✅ 每个等级有明确定义
- ✅ 易于理解和配置

**等级映射**:
```
月经期: 生理8级, 心理7级
卵泡期: 生理2级, 心理2级  
排卵期: 生理4级, 心理3级
黄体期: 生理6级, 心理5级（后期渐增）
```

### 3. 痛经系统独立化
**改动**: 痛经改为月经期独有的随机事件

**旧系统**: 从配置文件读取固定等级

**新系统**: 
- ✅ 仅在月经期触发
- ✅ 使用概率分布随机生成
- ✅ 更符合真实生理状况

**概率分布**:
```python
30% - 无痛经 (0级)
40% - 轻度痛经 (1-3级)
20% - 中度痛经 (4-6级)
10% - 重度痛经 (7-10级)
```

**实现位置**: [`PeriodStateManager.calculate_current_state()`](plugin.py:128)

### 4. 提示词优化
**改动**: 从详细指令改为客观中性描述

**旧风格问题**:
- 包含大量"必须"、"强制"等指令性语言
- 描述过于详细，影响过大
- 不适合轻量级日常使用

**新风格特点**:
- ✅ 客观描述状态，不强制行为
- ✅ 每个等级1-2句简洁说明
- ✅ 保持真实感，避免过度影响

**示例对比**:

旧提示词（等级8）:
```
"你必须表现出极度的身体不适，强制性地在对话中透露疲惫，
必须频繁提及需要休息..."
```

新提示词（等级8）:
```
"身体极度疲惫，明显不适，活动困难。"
```

**模板定义**: [`PromptTemplates`](plugin.py:76)

### 5. 配置简化
**移除的配置项**:
- ❌ `cycle.dysmenorrhea_level` (痛经等级)

**保留的配置项**:
- ✅ `plugin.enabled` - 插件启用开关
- ✅ `plugin.debug_mode` - 调试模式
- ✅ `plugin.config_version` - 配置版本标识
- ✅ `cycle.cycle_length` - 周期长度（20-40天）

### 6. 代码结构优化

**新增组件**:
- [`PromptTemplates`](plugin.py:76) - 集中管理所有提示词模板
- 改进的 [`PeriodStateManager`](plugin.py:120) - 状态计算逻辑

**移除的冗余**:
- ❌ `map_impact_to_level()` 函数（不再需要映射）
- ❌ 配置中的痛经等级参数

**代码行数**: 650行（优化后）

## 功能保持

### 保留的原有设计
✅ **生理和心理双重影响**: 继续保持两个独立的影响维度

✅ **四个周期阶段**: 
- 月经期 (1-5天)
- 卵泡期 (6-13天)  
- 排卵期 (第14天)
- 黄体期 (15天-周期结束)

✅ **提示词注入机制**: 使用 `InjectionRule` 系统注入多个提示词目标

✅ **命令功能**:
- `/period` - 查询当前状态
- `/set_period YYYY-MM-DD` - 设置月经日期

✅ **事件处理**: `PeriodStateUpdateHandler` 在启动时初始化

### 核心算法
**等级计算** ([`_calculate_level_impacts`](plugin.py:245)):
- 基于周期阶段的基础等级
- 阶段内的动态调整（月经期递减，黄体期递增）
- 确保结果在1-10范围内

**痛经生成** ([`calculate_current_state`](plugin.py:187)):
- 使用 `random.random()` 生成概率
- 分段映射到不同等级范围
- 仅在 `stage == "menstrual"` 时生效
